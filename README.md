# CKAD Trainer

A CLI tool for generating Certified Kubernetes Application Developer (CKAD) practice scenarios using LLMs.

## Features

- Generate CKAD practice scenarios across all CKAD skill areas
- Per-task validation with ✓/✗ feedback and expected vs. actual output
- Safe checks: only read-only `kubectl` commands, executed without a shell
- Each scenario runs in its own namespace with setup and cleanup commands
- Hints and solutions for every task
- Supports multiple LLM providers (OpenAI and OpenRouter)

See [ROADMAP.md](ROADMAP.md) for what's coming next, including an interactive practice mode.

## Installation

### Prerequisites

- Go 1.21 or higher
- A local Kubernetes cluster — any of the following works:
  - **Minikube**
  - **kind** (Kubernetes in Docker)
  - **Docker Desktop Kubernetes**
  - **Any standard local Kubernetes cluster**
- API key for **OpenAI** or **OpenRouter**

### Building from Source

```bash
git clone https://github.com/galalen/ckad-trainer.git
cd ckad-trainer
go build -o ckad-trainer main.go
```

## Usage

### Environment Variables

You can set the following environment variables instead of using command-line flags:

```bash
export OPENAI_API_KEY="your-openai-api-key"
export OPENROUTER_API_KEY="your-openrouter-api-key"
```

### Generating Scenarios

```bash
# Generate scenarios using OpenRouter
./ckad-trainer generate --provider openrouter --api-key your_key --count 3

# Generate 5 scenarios using OpenAI
./ckad-trainer generate --provider openai --api-key your_key --count 5

# Customize model and parameters
./ckad-trainer generate --provider openai --model gpt-4o --temperature 0.8 --count 10

# Focus on one skill area, generating 4 scenarios in parallel
./ckad-trainer generate --topic ingress --count 4 --concurrency 4
```

Running `generate` again appends new scenarios (`scenario-06`, `scenario-07`, …) instead of overwriting existing ones.

Each scenario is written to `scenarios/scenario-NN/`:

- `scenario.md` — description, setup commands, tasks and cleanup (no spoilers)
- `scenario.json` — the full scenario including hints, solutions and checks

Before starting a scenario, run the commands in its **Setup** section (they create the scenario's namespace `ckad-scenario-NN`).

### Validating Scenarios

```bash
# Validate a specific scenario
./ckad-trainer validate --scenario 1

# Validate all scenarios
./ckad-trainer validate --all

# Validate scenarios in a custom directory
./ckad-trainer validate --all --dir ./my-scenarios
```

Example output:

```
scenario-01: Web rollout
  ✓ 1. Create deployment web with 3 replicas
  ✗ 2. Update image to nginx:1.25
      - image is nginx:1.25
        expected: nginx:1.25
        got:      nginx:1.24
  1/2 tasks passed
```

Scenarios generated by older versions use a `validate.sh` bash script. Because those scripts are arbitrary LLM-written code, they only run when you pass `--allow-scripts` after reviewing them.
